# SitePulsar Cursor Plugin

Remote MCP for Agent Experience Optimization (AEO): measure how findable, readable, and usable any website is to AI agents.

- MCP endpoint: `https://mcp.sitepulsar.ai/mcp` (Streamable HTTP)
- Auth: OAuth (WorkOS) when connecting in Cursor
- Homepage: https://www.sitepulsar.ai
- Privacy: https://www.sitepulsar.ai/privacy
- Support: info@sitepulsar.ai

Install from the Cursor Marketplace, or add the MCP URL under Cursor Settings → MCP.
